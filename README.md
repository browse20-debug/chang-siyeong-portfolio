# Chang Siyeong — Photographer Portfolio

패션·룩북·커머스·광고 촬영을 위한 개인 포트폴리오 웹사이트입니다.

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

브라우저에서 터미널에 표시된 로컬 주소를 열면 됩니다.

## 사진과 문구 바꾸기

대부분의 내용은 `app/content.ts` 한 파일에서 바꿀 수 있습니다.

- `profile`: 이름, 소개, 이메일, 인스타그램, 메인 사진
- `services`: 작업 분야
- `projects`: 브랜드명, 분야, 연도, 대표 사진, 설명, 크레딧, 브랜드별 상세 사진
- `projects`의 한 항목이 한 브랜드이며, 브랜드를 추가하면 홈과 상세 페이지가 자동으로 생성됩니다.
- 각 브랜드의 `gallery`에 사진을 추가하면 해당 브랜드의 하단 썸네일과 전체보기에도 자동으로 반영됩니다.
- 이미지는 웹 주소 또는 `public/` 폴더에 넣은 로컬 파일 경로(`/photo.jpg`)를 사용할 수 있습니다.

현재 작품 사진은 레이아웃 확인용 Unsplash 샘플입니다. 공개 전에 본인 사진과 실제 프로젝트 정보로 교체하세요.

## 주요 구조

- `/`: 전체 화면 인트로, 세로형 WORK 브랜드 목록, 소개, 연락처
- `/projects/[slug]`: 브랜드별 중앙 슬라이드, 하단 썸네일, 전체보기 그리드, 설명·크레딧, 다음 브랜드
- `app/globals.css`: 색상, 글꼴, 간격, 애니메이션, 모바일 레이아웃
- `public/og.png`: 링크 공유 미리보기 이미지

## 디자인 원칙

레퍼런스의 이미지 중심 흐름과 절제된 내비게이션을 참고하되, 비대칭 편집 그리드, 세리프 타이포그래피, 아이보리·블랙 색상과 독자적인 상세 페이지 전환으로 새롭게 구성했습니다.
